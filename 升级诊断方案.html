03会实际伤害使用体验的代码问题

这几个不是"优化建议"，是真会让你在刷题时抓狂的 bug，建议本周先修掉。
1. 随机练习会在你提交答案后重新洗牌
QuizPage.tsx 的 questions 用 useMemo 依赖了 records.wrongIds，而 sort(() => Math.random()-0.5) 在每次重算时执行。答完一题 → records 更新 → 列表重排 → 你看到的下一题是随机的另一道，且当前题可能突变。同时这个洗牌算法本身有偏。
2. 错题重做答对最后一道会白屏卡死
答对后该题从 wrongIds 移除 → 列表长度 -1 → currentIndex 越界 → currentQuestion 为 undefined，卡片不渲染，没有"完成"提示也没有返回按钮可用。
3. 统计数据会被重复刷题无限灌水
use-storage.ts 中 alreadyAnswered 只保护了 answeredIds/correctCount/totalCount，但 byDirection 和 dailyRecords 每次都无条件 +1。同一题刷 10 遍，方向正确率就会失真，统计页的数字不可信。
4. 错题"一次答对即移出" → 假性掌握
当前逻辑：correct ? 从 wrongIds 移除 : 加入。你只是记住了答案，题就消失了。正确做法是连续答对 2–3 次才移出，并记录累计错误次数。
5. README 承诺的两个功能实际没实现
README 写了「应用内导出/导入 JSON 备份」和「PWA (Service Worker 离线缓存)」，但全库搜索无 Blob/download 相关代码，public/ 里也只有 manifest.json、没有 Service Worker。手机断网就用不了，换浏览器数据直接丢。
6. 缺少基础检索能力
416 题没有搜索框、没有收藏/标记、没有笔记。遇到一道想回头看的题，只能靠运气再刷到。

04升级优先级：先做什么，后做什么

按"对省一分数的贡献度"排序，不是按实现难度。P0 是考前必做，其余可以边赛边补。
P0省赛前必做 · 直接决定分数
1
限时模考引擎
内置两档官方规格：省初赛 60 题 / 60 分钟、省复赛 150 题 / 120 分钟。需含：全局倒计时、题卡导航（可跳题/回看）、标记待定、强制交卷、成绩报告（得分 + 各方向正确率 + 用时曲线）。
为什么第一：省复赛 150 题 120 分钟 = 平均 48 秒/题。没练过 pace 的队伍，普遍做不完卷。这是最容易拉开 200–400 分差距的地方。
2
多选题专项扩容到 150+
现有 17 道多选远远不够。优先把数通（OSPF/BGP/STP/VLAN）、安全（防火墙策略/VPN）、WLAN 的高频考点改写成多选，并支持单选题 0.5 分、多选题 1 分、判断题 0.5 分的分值体系。
为什么第二：多选分值高、容错率低，是省赛真正的分水岭。训练量不足 = 白送分。
3
判断题降权 / 改造
87 道判断题在考场上不会出现。建议：默认折叠，标注"非考试题型"，或批量改写为单选（判断题本质是二选一，改写成本极低）。
为什么第三：21% 的训练时间目前花在了不考的题型上。
4
错题本升级为间隔重复（SRS）
记录每道题的错误次数与最近答题时间；连续答对 2 次才移出错题本；按遗忘曲线安排今日复习队列。
为什么第四：从"见过"到"考场能选对"，中间差的就是重复次数。
5
修掉上面 6 个 bug
尤其是随机重排、错题白屏、统计灌水这三个。
为什么第五：统计数字不可信，就没法判断自己哪弱，整个 App 的决策价值会归零。
P1效率与覆盖度 · 有余力就做
6
DCN 方向补到 80+ 题
补齐 VXLAN/EVPN、Fabric、iStack/CSS、数据中心网络架构等考点，并把 12 个悬空 knowledgeId 与 20 个空知识点补上或删除。
7
难度分级（HCIA / HCIP / HCIE）
给每题打标，支持"初赛模式（IA 为主）"和"复赛模式（混入 IP 难度）"两档切换。
8
团队模式
3 人组队，各自的方向雷达图叠加成"团队能力图"，自动标出三人共同的弱项 —— 那才是队伍的真实短板。
9
考点热力图（对齐官方大纲权重）
按官方"路由协议 / 二层交换 / IPv6 / 数据中心 / 防火墙 / VPN / WLAN 组网"七大块做权重可视化，直接告诉你时间该往哪投。
10
数据备份与恢复
兑现 README 的承诺：导出/导入 JSON，并把 localStorage 换成 IndexedDB 或加轻量云同步，并补上真正的 Service Worker。
P2打磨项 · 赛后或碎片时间做
11
题目搜索 / 收藏 / 笔记
支持关键词搜题干与解析，允许给题加个人笔记。
12
首屏性能：题库分片懒加载
quizzes.ts 599 KB 单文件全量打进主包，叠加 ECharts + Framer Motion，手机首屏偏慢。建议按方向拆包 + 路由级懒加载，ECharts 改为按需引入。
13
实验速查扩充（为全国赛储备）
现在只有 6 条。虽然省赛不考实验，但配置命令题会以理论形式出现；进全国赛后这块就是主战场。
